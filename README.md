# Keydris

**Authority before action.**

Keydris is an authorization control plane for AI agents: an operator assigns bounded authority through policy, Keydris evaluates each governed action at action time, returns **ALLOW**, **REJECT**, or **APPROVAL REQUIRED**, and records the decision as reviewable evidence.
